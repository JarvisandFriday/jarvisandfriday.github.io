# ARC Suspensions — TEST COPY of www.arcsuspension.in

Static, read-only visual copy of the public pages of https://www.arcsuspension.in for preview only.

* Every page is `noindex,nofollow`; `robots.txt` disallows everything.
* Cart, checkout, login, wishlist, enquiry and other forms are disabled here and send visitors to the live shop.
* The live shop is **https://www.arcsuspension.in** — orders are only taken there.

Built by `build.sh` (polite GET-only crawl, 1 s between requests) + `postprocess.py`, deployed by GitHub Actions.
